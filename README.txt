Fayette County Anomaly Atlas — Home Screen App

This is a Progressive Web App (PWA). To install it on an iPhone Home Screen, it must be hosted on an HTTPS website.

Fastest deployment options:
1. GitHub Pages
2. Netlify Drop
3. Cloudflare Pages
4. Vercel

Upload the contents of this folder so index.html is at the site root.
Then open the HTTPS site in Safari on the iPhone and choose:
Share → Add to Home Screen → Add

The app will launch in standalone mode from its Home Screen icon.
